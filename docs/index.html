slothNtidy Notes Sorter.

Notes from all your WhatsApp class groups, sorted by syllabus unit in one click. Duplicates and circulars removed, and the topics nobody has shared yet flagged in red, before exam night.

What it does

From WhatsApp chaos to exam-ready.

01

Sorts by your syllabus

Enter your units once. Every PDF and photo of notes lands in the right unit folder with a clean name.

02

Throws out the noise

Fee circulars, notices, re-shared copies and the same page photographed twice are removed, with a reason for each. Nothing is deleted.

03

Shows your gaps

Every subtopic is ticked only when it appears on an actual page, so you see what is missing and can ask your class in time.

Install on Windows

Three steps.

  1. Download the installer with the button above. If your browser warns about the file, choose Keep.
  2. Double-click Install-slothNtidy.bat. If a blue box says "Windows protected your PC", click More info → Run anyway. Wait 10–15 minutes while it downloads the app, the AI model and the OCR reader. Click Yes if Windows asks permission.
  3. Double-click the sloth icon on your Desktop. slothNtidy opens in your browser. Keep the black window open while you use it.

If the installer says Python is missing, it opens the Python download page: install it, tick "Add python.exe to PATH", and run the installer again.

Install on Mac / Linux

One line.

  1. Open Terminal (Mac: press Cmd + Space, type Terminal, press Enter).
  2. Paste this line and press Enter:curl -fsSL https://raw.githubusercontent.com/adeeb-builds/slothNtidy/main/install.sh | bash
  3. Start it any time with:~/slothNtidy/run.sh

Mac needs Homebrew for the OCR reader (brew install tesseract); the installer tells you if it is missing.

How to use it

Export, drop, sort.

  1. In WhatsApp, open a class group → ⋮ → More → Export chat → Include media (iPhone: tap the group name → Export Chat). Get the .zip onto your laptop.
  2. In slothNtidy, enter your syllabus once, then drop the .zip files of all your groups on the Import page.
  3. Press Sort my notes. Open your sorted folder, or download one merged PDF per unit.
Private by design

Nothing leaves your laptop.

Class chats contain names and phone numbers, so slothNtidy runs entirely on your own computer. The AI model (MiniLM) and the OCR reader (Tesseract) are open source and run locally. No account, no cloud, no API keys.

It is a student project: neat handwriting reads well, messy handwriting may land in "Needs review" instead of being guessed. Coverage means covered in the notes you received, not a guarantee for the exam.
